# Cap's shared coding workspace

This directory contains the repositories Cap may work in:

- `vw-site` — the public Velocity Work website
- `vw-hq` — the internal Velocity Work HQ application
- `vw-crm` — CRM data, automation, and its `ui` application
- `vw-dashboards` — client dashboards and reporting application

Before inspecting, editing, testing, or running Git commands, identify the
repository named by the request and change into that repository (or the mapped
task worktree). Read and follow that repository's applicable `AGENTS.md` files.
Repository instructions override this routing file for work inside that repo.

Do not modify a sibling repository unless the request explicitly requires it.
If the intended repository is ambiguous and the choice would materially change
the work, ask which repository is intended before editing.
